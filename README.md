A tiny Node program that writes one kind, funny fortune for the houseplant on the windowsill to `entry.txt` — a single line of at most 120 characters, in the voice of a fortune teller who has been watching the plant's newest leaf take its sweet time. Run it with plain `node main.ts`; it reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes the fortune there.
